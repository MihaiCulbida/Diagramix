# Diagramix

A browser-based flowchart editor. No login, no install, open and draw.

## Features

- **Shapes**: terminator, rectangle, rhombus, parallelogram, hexagon, document, file, text, arrow, line
- **Multi-select**: drag to select or hold `Ctrl` and click
- **Resize**: 8-handle resize on all shapes
- **Style panel**: fill color, stroke color, stroke width, font size, bold/italic/underline, text align, line height
- **Lines & arrows**: drag endpoints, double-click to add midpoints, right-click midpoint to remove
- **Pages**: add, rename, delete, switch between pages
- **Undo / Redo**: `Ctrl+Z` / `Ctrl+Y` or toolbar buttons
- **Copy / Paste**: `Ctrl+C` / `Ctrl+V`
- **Grid**: toggle visibility and snap-to-grid
- **Pan**: hold `Ctrl` and drag the canvas
- **Notes**: floating draggable notepad, saved to localStorage
- **Fullscreen**: hides header, footer, and toolbar
- **Dark mode**: toggle light/dark theme
